# Бэкстейдж 🎙💜

Приватная стриминговая платформа — «Twitch для платных подписчиков» с авторизацией через Telegram и автоматической проверкой подписки на приватный канал.

- **Мульти-канальность**: несколько авторов трансляций одновременно, у каждого свой канал, stream key и приватный Telegram-чат для проверки.
- **Гейтинг контента**: эфир и чат доступны только платным подписчикам (status `member` / `administrator` / `creator` в приватном канале).
- **Twitch-подобный интерфейс**: витрина главной, разделы «В ЭФИРЕ / Главная / Клипы / Записи / Коллаборации / Расписание», живой чат с presence-счётчиком зрителей.
- **Mobile / Desktop**: адаптивный интерфейс (левый рейл → нижняя навигация, чат → сворачиваемый блок).
- **Легковесно, без Docker**: Next.js (App Router) + SQLite + маленький socket.io-сервис чата на Bun.

## Архитектура

```
┌─────────────────────────────┐      ┌──────────────────────────────┐
│  Next.js 16 (порт 3000)     │      │  chat-service (порт 3003)     │
│  ─ UI витрины/плеера/чата   │◀────▶│  ─ socket.io комнаты каналов  │
│  ─ REST API /api/*          │ HTTP │  ─ HMAC-токены, rate-limit    │
│  ─ Telegram Login + проверка│ внутрен│  ─ presence зрителей         │
│    подписки (Bot API)       │ вызовы│  ─ архив сообщений → БД      │
│  ─ Prisma + SQLite          │      │  Bun + TypeScript             │
└─────────────────────────────┘      └──────────────────────────────┘
              ▲                                     ▲
              │ HLS (m3u8)                          │ RTMP ingest
              │                                     │
   ┌──────────┴──────────┐               ┌──────────┴──────────┐
   │  OBS / энкодер      │──RTMP────────▶│  Медиа-сервер       │
   │  авторов            │               │  (MediaMTX и т.п.)  │
   └─────────────────────┘               └─────────────────────┘
```

| Компонент | Путь | Назначение |
|---|---|---|
| Основное приложение | `src/` | UI + API + авторизация + гейтинг |
| Чат-микросервис | `mini-services/chat-service/` | socket.io: комнаты, антифлуд, presence |
| Схема БД | `prisma/schema.prisma` | Users, Channels, Chat, Schedule, Clips… |
| Сиды витрины | `scripts/seed.ts` | демо-каналы, расписание, клипы |
| Шлюз | `Caddyfile` | проксирование `?XTransformPort=3003` |

## Быстрый старт

```bash
# 1. Зависимости
bun install

# 2. База + демо-данные
cp .env.example .env    # при необходимости поправьте DATABASE_URL
bun run db:push
bun scripts/seed.ts

# 3. Приложение (порт 3000)
bun run dev

# 4. Чат-сервис (порт 3003)
cd mini-services/chat-service
bun install
bun run dev
```

Откройте `http://localhost:3000`. Пока Telegram-бот не настроен — работает **демо-режим входа** (роль и статус «платного подписчика» выбираются в диалоге входа), плеер играет тестовый HLS-поток Mux.

## Настройка Telegram (продакшен)

1. **Бот**: создайте бота у [@BotFather](https://t.me/BotFather), скопируйте токен → `TELEGRAM_BOT_TOKEN`.
2. **Login Widget**: у BotFather выполните `/setdomain` и укажите домен сайта. Username бота → `TELEGRAM_BOT_USERNAME`.
3. **Приватный канал**: создайте приватный канал, добавьте бота его **администратором** (иначе Bot API не увидит участников). Числовой ID канала (начинается с `-100…`) → `TELEGRAM_CHAT_ID`; можно взять через пересылку сообщения боту [@userinfobot](https://t.me/userinfobot).
4. **Приглашение**: ссылка-инвайт в канал → `TELEGRAM_CHANNEL_LINK` (кнопка «Оформить подписку» в гейте).
5. **Админы**: ваши Telegram ID/username через запятую → `ADMIN_IDS`.
6. **Секреты**: задайте собственные `CHAT_SECRET` и `INTERNAL_SECRET` в `.env` **и** в окружении chat-сервиса (должны совпадать).

После этого вход в один клик через Telegram, статус подписки проверяется через `getChatMember` при входе и по кнопке «Проверить подписку».

## Приём вещания (RTMP)

Платформа не тянет медиа-сервер внутри — подключите любой RTMP→HLS-конвертер, например [MediaMTX](https://github.com/bluenviron/mediamtx):

```yaml
# mediamtx.yml
paths:
  saiko:
    source: publisher
```

Затем в **Панели управления** (шестерёнка в шапке, только для ADMIN) включите эфир и укажите HLS-адрес, например `http://media.example.com:8888/saiko/index.m3u8`. Stream key из панели используется как имя пути вещания (`rtmp://media.example.com/saiko`).
